# SalaRate
_Simple Employee Salary Calculator Web App_
**SalaRate** is a web application built with HTML, CSS, and JavaScript, designed to calculate employee salaries quickly and accurately. By combining intuitive form input with dynamic result display, SalaRate streamlines the process of computing wages based on hours worked and rate per hour. The application emphasizes form handling, dynamic DOM manipulation, and clean UI design, making it ideal for practicing web development skills.

The primary purpose of SalaRate is to provide a practical tool for salary calculations while reinforcing concepts in HTML, CSS, and JavaScript, offering a user-friendly experience for small businesses or individual use.

## FEATURES
✅ **Employee Input Form** – Input fields for Name, Hours Worked, and Rate per Hour.  
✅ **Real-Time Salary Computation** – Calculate salaries instantly based on user input.  
✅ **Dynamic Result Display** – Show results neatly on the right side of the page.  
✅ **Clean UI Design** – Professional and customizable interface.  
✅ **No Page Reload** – Prevents page refresh on form submission for seamless interaction.

## INSTALLATION
### Prerequisites
- A modern web browser (e.g., Chrome, Firefox, Edge).  
- No additional dependencies required, as the app runs entirely in the browser.

### Setup
1. Clone or download the project repository.  
2. Open `index.html` in a web browser to run the application.

### Verify Setup
Ensure the form loads correctly and calculations display without errors. No external libraries are required.

## USAGE
### Running the Application
Open the application by loading `index.html` in a web browser:
```
open index.html
```

### Example Workflow
1. **Open the App**: Load `index.html` in your browser.  
2. **Enter Employee Details**: Fill in the Name, Hours Worked, and Rate per Hour in the form.  
3. **Calculate Salary**: Submit the form to view the computed salary on the right side.  
4. **Review Results**: Check the displayed results, which update dynamically without page reload.

### Configuration
- No external configuration files are required.  
- Customize the UI by modifying the CSS in the project files.  
- Ensure a minimum screen resolution for optimal display (e.g., 1024x768).

## DEBUGGING
For issues, check the browser’s developer console (F12) for JavaScript or CSS errors. Common issues include:
- Invalid form inputs (e.g., non-numeric values for hours or rate).  
- Browser compatibility issues (use a modern browser).  
Report issues via GitHub Issues for detailed troubleshooting.

## PROJECT STRUCTURE

- `styles.css`: Stylesheet for UI design and layout.
