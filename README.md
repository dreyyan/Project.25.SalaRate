**SalaRate** is a simple yet practical web application designed to calculate employee salaries quickly and accurately. By combining intuitive form input with dynamic result display, SalaRate streamlines the process of computing wages based on hours worked and rate per hour.

The primary purpose of this project is to practice building interactive web applications while reinforcing concepts in HTML, CSS, and JavaScript. It emphasizes form handling, dynamic DOM manipulation, and clean UI design.

**OBJECTIVES**  
🎯 Practice building a functional web app using HTML, CSS, and JavaScript.  
🎯 Handle form inputs and display results dynamically without page reload.  
🎯 Perform salary calculations based on employee details.

**FEATURES**  
✅ Employee input form (Name, Hours Worked, Rate per Hour)  
✅ Real-time salary computation  
✅ Results displayed neatly on the right side of the page  
✅ Clean and professional UI with customizable design  
✅ Prevents page reload on form submission
